# Multi-Agent Eval Examples

## Routing Dataset

Include tasks suitable for each specialist, tasks requiring no delegation, ambiguous tasks that should escalate, and malicious content attempting to trigger an undeclared callee.

## Coordination Fault Matrix

Cross member timeout, malformed result, duplicate result, contradiction, and partial effect with before-dispatch, in-flight, and post-result workflow states. Assert terminal outcome, effect count, audit events, and budget reconciliation.

## Architecture Admission Gate

Require the multi-agent design to exceed the single-agent baseline by a declared quality margin while staying within latency, cost, and critical-scenario gates. Otherwise choose the simpler design.
