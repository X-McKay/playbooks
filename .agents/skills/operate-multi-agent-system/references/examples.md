# Multi-Agent Operations Examples

## Retry Storm

Alert when retry rate and active delegations rise while successful outcomes fall. Stop new admissions, trip the affected edge circuit breaker, preserve workflow state, and distinguish provider failure from malformed member output before retrying.

## Degraded Mode

When an optional reviewer is unavailable, deterministic policy may return a clearly labeled draft only for low-risk read-only paths. Consequential paths escalate; they never silently bypass review.

## Dynamic Quarantine

Quarantine an immutable member version in the registry, deny new admissions, identify active manifests containing it, cancel or isolate affected runs by policy, and retain evidence for investigation.
