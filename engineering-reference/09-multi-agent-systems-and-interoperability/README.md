# Part 9 — Multi-Agent Systems and Interoperability

**Status:** 0.5.0-draft.2 — draft

**Purpose:** Use multiple agents only when composition has measurable value and governed boundaries.

**Applicability:** Two or more model-driven agents contribute to one outcome, or A2A-style remote interaction is enabled.

**Output:** A system spec or composition manifest, typed interaction contracts and system evidence.
